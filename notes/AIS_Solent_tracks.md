## Technologies Involved

### 1. **Python Data Science & Tracking Libraries**
- **Stone Soup**:  
  - *Purpose*: Modular multi-target tracking framework.
  - *Usage in Script*: Handles reading, filtering, converting, modeling, predicting, updating, associating, initiating, and deleting tracks from AIS data.
  - *Modules Used*:  
    - `stonesoup.reader.generic` (CSVDetectionReader)
    - `stonesoup.feeder.time`, `stonesoup.feeder.filter`, `stonesoup.feeder.geo`
    - `stonesoup.models.transition.linear`, `stonesoup.models.measurement.linear`
    - `stonesoup.predictor.kalman`, `stonesoup.updater.kalman`
    - `stonesoup.gater.filtered`, `stonesoup.hypothesiser.distance`, `stonesoup.measures`
    - `stonesoup.dataassociator.neighbour`
    - `stonesoup.initiator.simple`, `stonesoup.deleter.time`
    - `stonesoup.tracker.simple`

### 2. **Geospatial Data Handling**
- **utm**:  
  - *Purpose*: Converts between latitude/longitude and UTM (Universal Transverse Mercator) coordinates.
  - *Usage in Script*: Converts processed track coordinates back to lat/lon for mapping.

### 3. **Interactive Mapping & Visualization**
- **Folium**:  
  - *Purpose*: Python library for generating interactive Leaflet maps.
  - *Usage in Script*:  
    - Creates a map centered on the Solent.
    - Plots vessel tracks as colored polylines.
    - Adds clickable markers with vessel metadata.
    - Saves the map as an HTML file (AIS_Solent_Tracks.html).

### 4. **Web Technologies**
- **HTML, JavaScript, Leaflet.js**:  
  - *Purpose*: Underlying technologies for interactive maps in browsers.
  - *Usage*:  
    - The HTML file generated by Folium contains embedded JavaScript (Leaflet.js) to render the map, tracks, and markers interactively.

---

## How It All Connects

- **Data Ingestion**:  
  - AIS data is read from a CSV using Stone Soup’s CSVDetectionReader.
- **Preprocessing**:  
  - Data is filtered (one detection per vessel per minute), reduced by MMSI, and converted from lat/lon to UTM coordinates for tracking.
- **Tracking**:  
  - Stone Soup builds a multi-target tracker using Kalman filters, associators, initiators, and deleters to follow vessel movements.
- **Visualization**:  
  - After tracking, the results (track coordinates and metadata) are converted back to lat/lon.
  - Folium is used to plot these tracks and markers on an interactive map.
  - The map is saved as an HTML file, which uses Leaflet.js to display in the browser.

---

## Summary

This workflow demonstrates a full pipeline for maritime vessel tracking using Python:
- **Stone Soup** provides the tracking logic and data management.
- **utm** handles geospatial coordinate conversion.
- **Folium** (with Leaflet.js under the hood) visualizes the results interactively in a browser via HTML and JavaScript.

The result is a browser-based interactive map showing vessel tracks and metadata, generated entirely from Python code and open-source libraries.
